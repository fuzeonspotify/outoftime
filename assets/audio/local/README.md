# Local music files

Place Casey/FuzeXO's original exported song masters in this folder.

Use these filenames for the current prototype:

- `okay.ogg`
- `pontiac.ogg`
- `rockstar.ogg`
- `circles.ogg`
- `out_of_time.ogg`

The audio files themselves are ignored by Git so unreleased masters are not uploaded to the public repository.

Recommended game exports:

- OGG Vorbis
- 44.1 kHz or 48 kHz
- Stereo
- Keep the original WAV/FLAC masters backed up elsewhere

Instrumental versions and stems can be added later for dialogue-safe transitions and adaptive music.

# Local music files

Place Casey/FuzeXO's original game-ready song exports in this folder.

Use these filenames:

- `okay.ogg`
- `pontiac.ogg`
- `rockstar.ogg`
- `circles.ogg`
- `out_of_time.ogg`

The audio files are ignored by Git so unreleased masters are not uploaded to the public repository. Missing files do not block gameplay; the game falls back to its procedural ambience and sound effects.

Recommended exports:

- OGG Vorbis
- 44.1 kHz or 48 kHz
- Stereo
- Dialogue-safe game edit where needed
- Original WAV or FLAC masters backed up separately

Instrumental versions and stems can be introduced later for more advanced adaptive transitions without changing these public repository rules.

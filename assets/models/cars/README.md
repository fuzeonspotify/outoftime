# Custom bridge car

Place the downloaded CGTrader Porsche 911 Turbo model in this directory using one of these exact names:

- `porsche_911_turbo.glb` (preferred)
- `porsche_911_turbo.gltf`

The startup preloader checks these project-bundled files before downloading or loading any fallback bridge vehicle.

Source model: CGTrader model ID `3721426`, created by `nvnwijesinghe` under the license displayed on its product page. Keep any texture and `.bin` files beside the `.gltf` file when using the separate glTF format.
